# clothes-drying-rack
clothes-drying-rack 3D CAD model for 3D printing

Requirements
- Clothes/Laundry Drying Rack 
- Rack should be Collapsible/folding for storage and Portable
- Heavy Duty
- length - 80 inches, height 51 inches
- locking hinges for added stability
- 3 retractable rods offer ample drying space for shirts, pants, skirts, sheets, and blankets
- Anti-Slip Feet
- Use freeCAD python to create 3D CAD model
